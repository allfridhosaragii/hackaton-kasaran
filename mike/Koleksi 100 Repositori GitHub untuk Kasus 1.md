# Direktori 100 Repositori GitHub Open-Source
## Hackathon GDG on Campus ITB – Kasus 1: Kampus dan Pembelajaran yang Lebih Cerdas

Koleksi 100 repositori open-source ini dikurasi khusus untuk tim sebagai referensi arsitektur kode, modul siap pakai, logika AI/RAG, deteksi afektif *client-side*, serta antarmuka web modern.

---

### Kategori 1: Framework LLM, Agen, & Socratic Prompting (No. 1–15)
Repositori untuk menyusun alur berpikir AI, *chain-of-thought*, penalaran langkah-demi-langkah, dan *agentic workflow*.

1. [langchain-ai/langchain](https://github.com/langchain-ai/langchain) – Framework orkestrasi aplikasi berbasis LLM dan agen terpopuler.
2. [run-llama/llama_index](https://github.com/run-llama/llama_index) – Framework data context augmentation untuk menghubungkan data perkuliahan dengan LLM.
3. [microsoft/autogen](https://github.com/microsoft/autogen) – Framework multi-agent untuk simulasi interaksi tutor, penguji, dan evaluator.
4. [crewAIInc/crewAI](https://github.com/crewAIInc/crewAI) – Framework orkestrasi tim agen AI kolaboratif.
5. [Significant-Gravitas/AutoGPT](https://github.com/Significant-Gravitas/AutoGPT) – Arsitektur agen semi-otonom yang memecah tugas besar menjadi sub-tugas kecil.
6. [guidance-ai/guidance](https://github.com/guidance-ai/guidance) – Bahasa kontrol interleave untuk output LLM dengan regex dan constraint ketat.
7. [outlines-dev/outlines](https://github.com/outlines-dev/outlines) – Pembangkitan teks terstruktur dengan jaminan format JSON Schema untuk inferensi cepat.
8. [google/generative-ai-js](https://github.com/google/generative-ai-js) – SDK resmi Google Generative AI (Gemini) untuk JavaScript/TypeScript.
9. [google/generative-ai-python](https://github.com/google/generative-ai-python) – SDK resmi Google Gemini untuk Python.
10. [f/awesome-chatgpt-prompts](https://github.com/f/awesome-chatgpt-prompts) – Ratusan koleksi persona prompt, termasuk instruktur Sokratik dan tutor koding.
11. [promptslab/Awesome-Prompt-Engineering](https://github.com/promptslab/Awesome-Prompt-Engineering) – Kumpulan makalah, teknik, dan repositori prompt engineering terarah.
12. [dair-ai/Prompt-Engineering-Guide](https://github.com/dair-ai/Prompt-Engineering-Guide) – Panduan komprehensif implementasi prompt Sokratik, Few-shot, dan Chain-of-Thought.
13. [transformerlab/transformerlab](https://github.com/transformerlab/transformerlab) – Platform lokal untuk evaluasi dan tuning model open-source.
14. [lm-sys/FastChat](https://github.com/lm-sys/FastChat) – Platform backend serving, evaluasi, dan orkestrasi model percakapan.
15. [huggingface/transformers](https://github.com/huggingface/transformers) – Ekosistem model transformer machine learning terlengkap.
